# Bar Inventory MVP V0.1

## Inicio rápido
1. Instala Python 3.11 o superior.
2. Abre una terminal en esta carpeta.
3. Ejecuta: `pip install -r requirements.txt`
4. Ejecuta: `streamlit run app.py`
5. Usuario inicial: **Admin** / PIN **1234**.

## Prueba recomendada
1. Administración: agrega las cervezas y licores reales.
2. Crea cócteles y recetas.
3. Haz un Cierre.
4. Haz una Apertura y verifica que el cierre anterior quede precargado.
5. Registra ventas POS por día o rango semanal.
6. Revisa Dashboard y genera PDF.

Incluye Cerveza, Licor y Cócteles; apertura/cierre; Bar/Bodega; proveedor; transferencias; pruebas/desperdicios/cortesías; POS; recetas; roles y PDF.
