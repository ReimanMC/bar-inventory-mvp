Important operational note
--------------------------
V0.5.7 is an MVP hardening release. SQLite still runs on Streamlit's local filesystem, while Supabase Storage is the durable recovery layer. For a future production deployment with stronger multi-instance transactional guarantees, migrate the live database to Supabase PostgreSQL rather than coordinating the live database through object storage.
